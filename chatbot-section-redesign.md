# Redesign da Seção do Assistente Virtual - RioTerra

## Problemas Identificados na Versão Atual
- Mascote usado apenas como fundo desfocado e pouco visível
- Layout muito simples e sem destaque visual
- Falta de interatividade e elementos que chamem atenção
- Botão do WhatsApp não tem conexão visual com o mascote

## Novo Conceito de Design

### Layout Principal
- **Grid assimétrico** com o mascote como elemento protagonista
- **Duas colunas**: uma para o mascote (maior) e outra para o conteúdo
- **Background gradiente** que complementa as cores do mascote
- **Elementos flutuantes** ao redor do mascote para dar dinamismo

### Uso Inteligente do Mascote
1. **Posicionamento central-esquerdo** em tamanho grande e nítido
2. **Animações sutis**: 
   - Flutuação suave (hover effect)
   - Brilho pulsante na "folha" tecnológica
   - Partículas de dados flutuando ao redor
3. **Interatividade**: 
   - Hover no mascote destaca o botão
   - Animação de "acenar" quando o usuário se aproxima do botão

### Elementos Visuais Adicionais
- **Partículas de dados** (pontos e linhas) flutuando
- **Cards flutuantes** com informações sobre o assistente
- **Gradiente de fundo** verde-azul que combina com o mascote
- **Efeitos de luz** atrás do mascote

### Conteúdo Aprimorado
- **Título mais impactante** com destaque visual
- **Descrição em cards** separando os benefícios
- **Botão de ação** mais proeminente com animações
- **Indicadores visuais** de que é um assistente IA

### Responsividade
- **Mobile**: Mascote menor, layout em coluna única
- **Tablet**: Layout adaptado mantendo o protagonismo do mascote
- **Desktop**: Layout completo com todos os efeitos

## Tecnologias a Utilizar
- **Framer Motion**: Para animações suaves
- **CSS Gradients**: Para backgrounds dinâmicos
- **Transform/Translate**: Para efeitos de flutuação
- **Backdrop-filter**: Para efeitos de vidro
- **Box-shadow**: Para profundidade e destaque
